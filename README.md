# متجر العتيق (Al-Ateeq Store) 🛒📱

متجر إلكتروني متكامل وعصري للهواتف الذكية، السماعات الاحترافية، أجهزة اللابتوب، والإكسسوارات الأصلية.

## المميزات الرئيسية
- **واجهة مستخدم عربية كاملة (RTL)** متوافقة مع جميع أحجام الشاشات باستخدام Tailwind CSS وأيقونات Font Awesome.
- **معرض منتجات تفاعلي:** فلاتر للأقسام، بحث فوري، وقائمة مفضلة ديناميكية.
- **صفحة تفاصيل المنتج:** نمطان للعرض (نمط التقسيط والمعرض البصري + نمط جدول المواصفات الفنية).
- **سلة تسوق منبثقة (Drawer Cart):** إدارة المنتجات والكميات وحساب الإجمالي فورياً.
- **عروض التقسيط وخطط الدفع:** تكامل بصري مع خطط الدفع والتقسيط (valU, U, TRU, مايلو).

## التشغيل
افتح ملف `index.html` في أي متصفح ويب مباشرة.
